# Studio Knowledge Base

These 12 educational guides are original AI-assisted writing for Creator Studio Copilot. They are not manufacturer documentation. Fictional examples and calculations are labeled in the guides.

The authoring assistant checked the linked official pages or indexed excerpts and recorded the checked claims in `manifest.json`. This is not independent human technical review, a comprehensive plagiarism audit, or a guarantee that every inference is correct. No downloaded PDF text was used to assemble these files.

General concepts apply across the six supported products. Exact product specifications, version-specific commands, HDR delivery standards and current platform requirements are deliberately outside this corpus.
