# Reverb, delay and effects sends

## Create a space without losing the source
Reverb suggests a pattern of reflections and decay; delay creates discernible repetitions when the spacing is long enough. Both can supply depth or rhythm, but both also add energy that can obscure words or overlap the next phrase. More effect is not automatically more spacious in a useful way. Think about whether the listener should notice the room, the repeat, or simply a sense of depth.

An insert processes a track in its serial path. A send feeds a parallel effect path whose return is mixed alongside the original. Several tracks can share one reverb return while sending different amounts, which makes it easy to experiment with a common space. On a conventional shared reverb return, a fully wet setting avoids unnecessarily adding another copy of the dry source through that return. An insert's wet/dry control has a different balancing job.

## Pre-fader and post-fader choices
A post-fader send generally follows source-fader changes; this is often useful when the effect should fade with the source. A pre-fader send can remain independent of that move and is often useful for a monitor mix. Exact routing varies, so inspect the actual signal path rather than inferring it from a knob's position.

1. Create an effect return and verify where it reaches the mix.
2. Put a reverb or delay on that return and check its wet/dry setting.
3. Start with a low send amount from one source.
4. Change the source fader and verify that the effect follows as intended.
5. Listen to an entire phrase, including the silence after it.

## Original editing example
Imagine a presenter whose words are clear until the next sentence begins. The reverb tail from the previous sentence may be masking that entrance. First compare a shorter tail or a lower send. Brightening the entire voice with EQ can increase harshness without removing the overlap. A rhythmic echo can likewise need fewer repeats rather than more output volume.

## Misconceptions and boundaries
A send is not the same as duplicating the original track at full level. Turning down a return does not prove that it is no longer feeding another bus. Reverb cannot correct clipping or capture a missing performance. This guide covers general routing reasoning, not the exact bus creation commands in a particular DAW version.
